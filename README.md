# Officeファイル相互読み書き＆一括資料生成ツール

## 📌 概要
本ツールは、CSV、Excel、PowerPoint、Wordのいずれかのファイルから「表データ」を自動で読み込み、ボタン一つで新しく最適化された **Excel（データ集計）、PowerPoint（グラフ付きスライド）、Word（詳細報告書）の3文書を同時に一括生成・出力する** デスクトップアプリケーションです。

「毎月システムから出力されるCSVを、手作業でパワポのグラフやWordの報告書にコピペしている」といった不毛な定型業務を完全に自動化します。

## ✨ 主な機能

1. **マルチインポート対応（入力形式の自動判別）**
   - **CSV (`.csv`)**: UTF-8およびShift_JIS（Excel出力形式）の文字コードを自動判別して読み込みます。
   - **Excel (`.xlsx` / `.xls`)**: 指定されたファイルの1枚目のシートのテーブルデータを読み込みます。
   - **PowerPoint (`.pptx`)**: スライド内を検索し、最初に見つかった「表（テーブルオブジェクト）」からデータを抽出します。
   - **Word (`.docx`)**: 文書内を検索し、最初に見つかった「表（グリッド）」からデータを抽出します。

2. **3文書の一括新規出力（書き出し）**
   - **Excel**: 抽出したデータをきれいにまとめたシートを出力。
   - **PowerPoint**: 1列目を横軸、2列目を縦軸とした「売上/利益等の推移グラフ」を自動生成し、補足スライドを含めたプレゼン資料を出力。
   - **Word**: データを表形式で埋め込んだ、A4縦型の「事業詳細報告書」を出力。

3. **実用的なGUI（操作画面）**
   - マウス操作だけで入力ファイルと保存先フォルダを選択可能。
   - バックグラウンド処理（マルチスレッド）を採用しているため、データ処理中に画面が「応答なし」でフリーズしません。
   - エラーハンドリング機能を搭載し、万が一の読み込み失敗時も原因を画面上にわかりやすく表示します。

## 🛠 必要要件（動作環境）

Python 3.8 以上がインストールされている必要があります。また、以下の外部ライブラリを使用します。

```bash
pip install pandas openpyxl python-pptx python-docx
🚀 使い方
1. 起動方法
スクリプトが存在するディレクトリで以下のコマンドを実行します。

Bash
python ReportGeneratorApp.py
2. 操作手順
「入力元ファイル」の右側にある「選択...」ボタンを押し、元データ（CSV、Excel、パワポ、Wordのいずれか）を選択します。

「保存先フォルダ」の右側にある「参照...」ボタンを押し、成果物を保存したい場所（デフォルトはデスクトップ）を選択します。

「データを読み込んで3文書を一括生成」ボタンをクリックします。

処理が完了すると、「すべての資料生成が完了しました！」とポップアップが表示され、指定フォルダに以下の3ファイルが生成されます。

Converted_Data.xlsx (Excel)

Converted_Presentation.pptx (PowerPoint)

Converted_Report.docx (Word)

💡 インプットデータ（元ファイル）作成のコツ
プログラムがデータを正しく認識できるよう、入力するファイルは以下のルールに従って作成してください。

データの構造:
必ず1行目が「列名（ヘッダー）」になっている必要があります。（例: 1行目が「月, 売上, コスト」、2行目以降に具体的な数値）

Word / PowerPointを読み込ませる場合:
テキストとして書かれた数字は読み込めません。必ず「挿入」＞「表」機能を使って作成されたテーブルオブジェクトを配置してください。ツールはそのファイル内の一番最初に見つかった表を自動抽出します。

グラフの連動:
PowerPointに自動生成されるグラフは、読み込んだデータの「1列目が横軸（項目名）」、「2列目が縦軸（数値）」として連動します。

🔧 開発者向け：今後のカスタマイズ
本ツールは可読性を重視したクラス設計（Tkinter）で記述されています。実務に合わせて以下のような拡張が可能です。

PowerPointのデザイン変更: create_pptx 関数内を書き換えることで、社内の公式テンプレート（.potx）をベースにスライドを生成するように改良できます。

exe化（スタンドアロンアプリ化）:
pyinstaller を使用することで、Python環境のない他の社員のPCでも動く .exe ファイルに変換できます。

Bash
pip install pyinstaller
pyinstaller --noconsole --onefile ReportGeneratorApp.py
